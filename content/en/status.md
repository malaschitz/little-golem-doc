  Little Golem service status information

Little Golem consists of the public documentation, the web/mobile application
and the game API. A working documentation page does not by itself confirm that
the application and API are available.

Planned maintenance and known service-wide incidents are announced here when
needed. If a problem is not listed, try the application again and then use the
[contact page](/contact/) with the approximate time and the action that failed.

Do not include a password, login token or private game message in an incident
report.
